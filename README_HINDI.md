## 📖 Example: Web Development का Roadmap

### Phase 1: Web की बुनियाद (6-8 हफ्ते)
```
क्या सीखोगे?
✓ HTML (Website की skeleton)
✓ CSS (Styling)
✓ Git (Code manage करने का tool)

DSA सीखोगे:
→ Variables क्या होते हैं
→ Data types
→ Basic problem solving

Database:
→ अभी नहीं (बाद में)

Tools:
→ VS Code (Code editor)
→ Chrome DevTools
→ Git

Projects बनाओगे:
1. Apni portfolio website
2. Responsive landing page
```

### Phase 2: JavaScript सीखो (8-10 हफ्ते)
```
क्या सीखोगे?
✓ JavaScript (Website को interactive बनाओ)
✓ DOM manipulation
✓ API से data लो

DSA:
→ Arrays
→ Objects
→ Strings

Tools:
→ Node.js
→ Postman
→ npm

Projects:
1. Todo app (add/delete करो)
2. Weather app (API use करो)
3. Calculator
```

### Phase 3: React सीखो (10-12 हफ्ते)
```
Advanced website components बनाओ
→ React framework
→ Components aur State
→ Routing

Projects:
→ E-commerce interface
→ Social media feed
```

### Phase 4: Backend बनाओ (12-16 हफ्ते)
```
Database + Server
→ Node.js/Express
→ REST APIs
→ MongoDB/MySQL

Projects:
→ Complete REST API
→ Authentication system
→ Blog platform
```

### Phase 5: Job के लिए तैयारी (8-12 हफ्ते)
```
Resume + Interview + Deploy
→ Portfolio projects public करो
→ Interview practice
→ System design

Career Options:
→ Frontend Developer
→ Backend Developer
→ Full Stack Engineer
```
